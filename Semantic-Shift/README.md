This folder holds the modified code from the 2020 Sem Eval study. In order to use it you must first download the packages in the requirements.txt in Semeval2020-Task1/
 - note that the source code is quite old so a more recent version of torch is necessary. 


To get results place your model safetensors in the model/ folder and run main.py. This will generate results in semevel_results/english_results.csv. The original code used command line prompts and parsed fields from the prompts but main.py has been organized to do all of that from a central script.
